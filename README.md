# Шпион — игровой Telegram-бот

ает онлайн-комнаты и игру на одном устройстве, роли мирных игроков и шпиона, голосование, пользовательские наборы слов, историю партий, профиль, рейтинг и модерацию.

## Состав проекта

- `app/` — исходный код бота, игровой логики и работы с базой данных.
- `requirements.txt` — зависимости Python.
- `Dockerfile`, `docker-compose.yml` — запуск с MySQL в контейнерах.
- `Документация/` — пояснительная записка, содержание, приложения А, Б, В, полный документ в DOCX/PDF и редактируемые диаграммы draw.io.

В репозитории нет токена бота, нужно будет создать самому.

## Требования

Python 3.12 и MySQL 8.4, либо Docker с поддержкой `docker compose`. Нужны собственный токен бота от BotFather и числовой Telegram ID администратора.

## Запуск в Windows с установленным MySQL

1. Клонировать проект и установить зависимости:

```powershell
git clone https://github.com/wawgame123/SpyFallTelegramBot.git
cd SpyFallTelegramBot
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

2. Создать пустую базу и отдельного пользователя в MySQL. Заменить пример пароля своим:

```sql
CREATE DATABASE spy_game CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'spy'@'localhost' IDENTIFIED BY 'replace_with_your_password';
GRANT ALL PRIVILEGES ON spy_game.* TO 'spy'@'localhost';
```

3. В том же окне PowerShell задать настройки и запустить бота:

```powershell
$env:BOT_TOKEN = Read-Host 'Токен бота от BotFather'
$env:ADMIN_ID = Read-Host 'Числовой Telegram ID администратора'
$env:DATABASE_URL = Read-Host 'URL базы: mysql+pymysql://spy:пароль@localhost:3306/spy_game?charset=utf8mb4'
.\.venv\Scripts\python.exe -m app.main
```

Специальные символы пароля в `DATABASE_URL` должны быть URL-кодированы. База должна существовать до запуска, таблицы бот создаст сам. Для работы административных функций нужен корректный `ADMIN_ID`; имя пользователя само по себе не даёт прав администратора. Не запускайте одновременно два экземпляра с одним токеном.

## Запуск через Docker

Задать переменные окружения в текущем PowerShell:

```powershell
$env:BOT_TOKEN = Read-Host 'Токен бота от BotFather'
$env:ADMIN_ID = Read-Host 'Числовой Telegram ID администратора'
$env:MYSQL_PASSWORD = Read-Host 'Новый пароль пользователя spy'
$env:MYSQL_ROOT_PASSWORD = Read-Host 'Новый пароль root для MySQL'
docker compose up --build -d
docker compose logs -f bot
```

Для контейнерного варианта используйте в `MYSQL_PASSWORD` длинный пароль из латинских букв и цифр: Compose вставляет его в URL подключения. Порт MySQL наружу не публикуется, данные сохраняются в томе `mysql_data`. Контейнеры проверяют доступность MySQL и работоспособность цикла polling бота.

Остановить контейнеры: `docker compose down`. Эта команда сохраняет том с данными.

## Первое использование

Откройте чат с ботом и отправьте `/start`. Новая база не содержит готовых наборов и истории чужих игр. Через раздел «Наборы слов» создайте собственный набор, добавьте слова и выберите его при настройке игры. Для публикации набора нужно не менее 10 слов. Доступные в интерфейсе импорт и экспорт позволяют переносить собственные наборы.

Для онлайн-партии создайте комнату, пригласите участников кодом или ссылкой, выберите набор и параметры игры. Для игры на одном устройстве используйте соответствующий пункт главного меню.

## Настройки окружения

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен вашего Telegram-бота, обязателен |
| `DATABASE_URL` | Подключение SQLAlchemy к MySQL; в Docker задаётся автоматически |
| `ADMIN_ID` | Числовой Telegram ID администратора |
| `ADMIN_USERNAME` | Необязательное отображаемое имя администратора |
| `PROXY_URL` | Необязательный адрес прокси для Telegram |
| `BOT_HEALTH_FILE` | Необязательный путь к файлу состояния polling |

Настройки можно хранить локально в `.env`, но такой файл исключён из Git и не должен публиковаться. Исходные документы и диаграммы находятся в папке «Документация».
